# Documentation

This directory documents the Campus Event Pass source snapshot. It is a **private, sanitized snapshot**: live contract addresses, transaction hashes, owner addresses, deployment records, hosted URLs and sample images are intentionally omitted. Replace placeholders such as `YOUR_CONTRACT_ADDRESS` with values from your own deployment.

| Document | Purpose |
| --- | --- |
| [`NFT_V2_DESIGN.md`](NFT_V2_DESIGN.md) | V2 dual metadata routes: generative 800×480 on-chain SVG plus optional per-token external metadata |
| [`NFT_V3_DESIGN.md`](NFT_V3_DESIGN.md) | V3 square 1024×1024 on-chain SVG and the reason for a new collection |
| [`EXTERNAL_METADATA_TEMPLATE.md`](EXTERNAL_METADATA_TEMPLATE.md) | JSON template and operating notes for `setExternalTokenURI` |
| [`CARD_ANIMATION.md`](CARD_ANIMATION.md) | Hover and click animation on the hero pass card |
| [`VALIDATION.md`](VALIDATION.md) | Test, build and browser evidence, with deployment identifiers omitted |
| [`DEPLOYMENT.md`](DEPLOYMENT.md) | Fresh Sepolia deployment, configuration, acceptance and troubleshooting |
